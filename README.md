# HSR PlayTools

为 Apple Silicon Mac 上通过 PlayCover 运行的《崩坏：星穹铁道》iOS 客户端直接启用**游戏原生 PC 界面与键鼠控制方案**，提供接近 PC 端的操作体验。

## 核心功能

- **直接启用游戏原生 PC 界面**：使用游戏原生 PC 界面与操作逻辑，让界面呈现和键鼠交互相互配合。
- **鼠标悬停候选效果**：鼠标移入按钮等 UI 控件时显示选中、高亮反馈，便于识别当前可操作的目标。
- **游戏自带鼠标指针**：使用游戏自带的光标样式，并通过 macOS 原生指针显示，兼顾视觉一致性与移动流畅度。
- **灵敏度自由调节**：在游戏内调整鼠标视角与滚轮灵敏度，适应不同鼠标、触控板和操作习惯。
- **游戏 UI 缩放**：在设置面板中调整界面比例，改善高分辨率窗口下的布局与显示尺寸。

通过 PlayCover 自定义插件加载一个 `HSRPlayTools.dylib` 即可使用，Lua 功能已集成在插件中。

## 功能特性

### 键鼠操作

- 支持多键组合输入、角色切换和快捷键操作。
- 支持鼠标移动视角、左键攻击和右键疾跑；右键疾跑适用于沉浸与自由光标状态。
- 每次启动首次进入大世界时自动捕获光标；失焦后释放，重新激活或重新登录后按 Alt 捕获。
- Alt 释放模式支持“按下切换”和“按住释放”，设置面板显示当前模式。
- 打开 Tab 轮盘时释放光标，并同步居中位置。
- 操作按钮、滑动条等 UI 控件以及光标回中时，保持游戏视角稳定。

### 光标与界面

- 使用游戏光标样式绘制 macOS 原生指针，保持固定尺寸。
- 为游戏 UI 提供悬停反馈，设置入口带淡白色悬停渐变。
- 支持鼠标灵敏度、滚轮灵敏度和界面缩放调节。
- 设置面板采用中文界面，打开、切换和关闭带淡入淡出过渡。
- 右上角叉号关闭面板，右下角显示版本号。

### Unity 控制台

- 完整显示 Unity 回调的原始日志消息，保留消息文本及其原有内容。
- 支持滚轮、拖动滚动和清空日志。
- 查看历史时保持滚动位置，停留底部时跟随新消息。
- 采用内存缓冲保留最近 40 条 Unity 日志消息。

## 默认设置

| 设置 | 默认值 |
| --- | --- |
| 鼠标灵敏度 | 3.0× |
| 滚轮灵敏度 | 3.0× |
| 界面缩放 | 80% |
| Alt 释放模式 | 按下切换 |

沉浸鼠标和滚轮桥接始终启用。设置会自动保存，下次启动优先使用已保存的值。

## 使用方式

1. 退出游戏，打开 PlayCover 中的游戏设置。
2. 在“杂项 → 自定义插件”中添加 `HSRPlayTools.dylib`。
3. 启动游戏，从 ESC 菜单中的 **增强工具** 入口打开设置面板。

更新时退出游戏，通过同一插件入口替换 dylib；移除时删除插件列表中的对应项。以上操作由 PlayCover 管理插件副本。

## 从源码构建

需要 Apple Silicon Mac、Xcode Command Line Tools 和 Python 3。在项目目录运行：

```sh
python3 build.py build
```

输出为 `HSRPlayTools.dylib`。C 和 Lua 源码分别维护，构建时自动将 Lua 嵌入 dylib；展示版本来自 `VERSION`。也可使用 VS Code 默认构建任务。

## 兼容性说明

适用于支持自定义插件的 PlayCover。本模块以固定地址应用适配；游戏构建变化时，需要同步更新适配地址。
